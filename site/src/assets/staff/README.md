# Staff portraits

One JPEG per person, named to match the key in `site/src/lib/staff-assets.ts`.
Cropped to a circle on the page, which keeps only the middle ~56% of a tall
photo — set `focus` in the person's .md file if the crop clips a head.

A person whose `photo` key is missing shows a "Photo needed" marker rather than
a broken image, so it is safe to add people before you have their portraits.
